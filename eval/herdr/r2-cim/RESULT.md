## Where the skill instructions were unclear, wrong or missing

File paths are under `~/.claude/skills/deckmark/`.

1. **`SKILL.md:126` (Scaffold example) omits `--dealt`.** The stamp then reads "by request" for a theme that was dealt (`scripts/theme.mjs:258`). The deal's own "next" line asks for `--dealt` (`scripts/theme.mjs:157`).
2. **`SKILL.md:126`: `--draw <seed>` is ambiguous.** It does not say the draw seed, not the deal seed. I passed the wrong one.
3. **`scripts/theme.mjs:311`: the scaffold says "fonts: Google Fonts link in `<head>`".** The written `deck/deck.html` has no Google Fonts link (grep count 0). `tokens.css` and `base.css` have no `@import` either. This is a bug: either the link is missing or the message is wrong.
4. **`scripts/theme.mjs:315`: the scaffold "next:" lines print `<repo>/skill/deckmark/...` paths.** `SKILL.md` says the skill lives in `~/.claude/skills/deckmark`. The canonical copy is not named.
5. **`SKILL.md:149` (Log): `log` writes to a path relative to the current directory** (`scripts/theme.mjs:22`). The example does not say to run it from the deck project. This is how the stray log happened.
6. **`scripts/theme.mjs`: `deal --log` and `draw --log` did not leave `.deckmark/log.json`** at the path I gave (`test/herdr/r2-cim/.deckmark/`). I could not find where they went. Unclear.
7. **`SKILL.md:82` (Facts): does not say whether `data-fact` tagging is required.** decklint gives a NOTE for 48 untagged facts. The lint passes without it.
8. **`SKILL.md:129` (Charts): no mention of `fmt.dp`.** `scripts/charts.mjs:23` prints whole numbers with no decimal. A waterfall total of 13.0 printed as "13". Fixed by passing `fmt: { dp: 1 }`. The skill should say to set `dp` to match the deck's decimal rule.
9. **`references/components.md:89` and `base.css:168`: `.fill` does not stretch content.** It grows the box, not the rows inside. A `.summary-rows.fill` in a `.stack` left the slide at 54% fill, which failed `empty-slide`. The doc says "takes the remaining height".
10. **`references/storylines/cim.md:7`: length is 30 to 60 pages.** There is no short-form variant for a 12 to 16 slide summary. I had to cut.
11. **`references/gates.md:38` (R2) says "legend".** A two-series stacked bar uses direct labels at the bar tops. It is not clear whether that counts as a legend. I did not need to waive it.
12. **`SKILL.md:51` (preflight): no schema for `.deckmark/preflight.json`.** I used `material`, `numbers_available`, `numbers_absent`, `confidential`. The skill does not name the fields.
13. **`SKILL.md` Step 6 says "Write only slides".** It does not say whether a generator script is allowed. I used one.
14. **`empty-slide` (gates.md § 3, R13) gives no path for a thin source.** The only options are "merge" or "cut". For a short summary the honest fix is to cut the slide count. The skill should say so.
